# 🎨 Website Build with Figma

This is a simple **card design project** built from a **Figma design** using **HTML5 and CSS3**.  
The project focuses on converting design to code and making it responsive.

## 🌐 Live Preview
👉 https://md-sakil352.github.io/websitebuldwithfigma/

## 📌 Project Overview
- Designed in Figma  
- Converted into real website layout  
- Fully responsive card design  
- Beginner-friendly project  

## 🚀 Features
- Clean and modern card UI  
- Responsive design (mobile-friendly)  
- Pixel-based layout from Figma  
- Simple and organized code  

## 🛠️ Technologies Used
- HTML5  
- CSS3  

## 🎯 Purpose
This project was created to practice **Figma to HTML/CSS conversion** and improve responsive design skills.
